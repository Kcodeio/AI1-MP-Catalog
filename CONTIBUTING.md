# Contributing to AI1

Thank you for your interest in contributing to **AI1**! Open source projects thrive when people collaborate, and all contributions—from bug fixes and feature requests to documentation improvements—are welcome.

---

## Code of Conduct

Please be respectful, constructive, and kind in all discussions, issues, and pull requests.

---

## How Can I Contribute?

### 1. Reporting Bugs
- Check the [Issues tab](https://github.com/) first to see if the bug has already been reported.
- If not, open a new issue describing:
  - What you expected to happen.
  - What actually happened.
  - Steps to reproduce the problem.
  - Error logs or screenshots (if any).

### 2. Suggesting Features & Enhancements
- Open an issue with the label `enhancement`.
- Clearly explain the use case and why this feature would be useful for AI1.

### 3. Submitting Code (Pull Requests)
We follow the standard GitHub Fork & Pull Request workflow:

1. **Fork the repository** to your own GitHub account.
